# Mood Tracker Design Examples

Meditation-inspired design directions for a mood tracker. Three distinct atmospheres, each with an interactive mobile prototype.

## Directions

### 1. Still Grove
Soft forest dawn — mist, moss, and quiet light. Mood check-in feels like stepping into a clearing.

- Open [`still-grove/index.html`](still-grove/index.html)
- Palette: sage, fog, soft sky, warm sand
- Motion: breath ring + mist drift

### 2. Night Harbor
Deep water at dusk — slate teal and a single warm amber cue. Evening reflection energy.

- Open [`night-harbor/index.html`](night-harbor/index.html)
- Palette: slate, deep teal, soft mist, amber accent
- Motion: ripple rings + soft wave shimmer

### 3. Soft Linen
Airy studio calm — oat linen and eucalyptus. Light, spacious, unhurried.

- Open [`soft-linen/index.html`](soft-linen/index.html)
- Palette: oat, charcoal, eucalyptus
- Motion: fabric drift + soft focus pulse

## Design principles

- Brand as the first-viewport hero (not a nav label)
- One job per screen: check in, reflect, or review
- Atmosphere over chrome — gradients and soft motion, not card grids
- Abstract mood marks instead of emoji faces
- Meditation-app pacing: space, breath, low noise
